### 📘 Blog Sitesi Ödevi – Patika.dev | Front-End Eğitimi

Bu proje, **HTML** ve **CSS** kullanılarak hazırlanmış basit bir blog sitesi örneğidir.  
Amaç, temel web geliştirme yeteneklerini pekiştirmektir.


### 📁 Dosya Yapısı

| Dosya            | Açıklama                           |
|------------------|------------------------------------|
| `index.html`     | Ana sayfa (Blog gönderisi özetleri) |
| `post.html`      | Örnek blog gönderisi detay sayfası |
| `styles.css`     | Tüm sayfalara ait stil dosyası     |
| `/img/` klasörü  | Blog gönderilerinde kullanılan görseller |

---

### 💡 Özellikler

- Responsive yapıda temel blog tasarımı  
- Menü navigasyonu (`<nav>`)  
- Blog kart yapısı (`<article>`)  
- Gölge efekti ve köşe yumuşatma (box-shadow, border-radius)  
- Sayfa sonu telif hakları (`<footer>`)


### 🧑‍💻 Kullanılan Teknolojiler

- HTML5  
- CSS3
- Responsive tasarım mantığı
